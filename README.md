# Tic-Tac-Toe 🎯

Live Demo: [https://rezwan1768.github.io/tic-tac-toe/](https://rezwan1768.github.io/tic-tac-toe/)

## Overview

A simple two-player Tic-Tac-Toe game where players take turns marking cells with X or O. The starting player alternates after each game reset to keep play balanced.

## Features

- Two-player turn-based gameplay
- Alternating first player after each reset
- Basic win/draw detection
- Responsive UI

## Technologies

- JavaScript
- HTML
- CSS
